# 秋日邮局视觉设计

主题：把秋天装进一封信。整体保持 16:9、37.1 秒及水彩拼贴节奏，各场景以信件递送为共同叙事。

## 主色

- 暖纸白 `#f5ecdc`：背景与留白。
- 陶土橙 `#bc593c`：枫叶、标签与边框。
- 酒红 `#752f40`：信箱、邮票、火漆和主要画布。
- 墨褐 `#45332c`：手写正文、树枝和信箱结构。
- 赭石 `#bd884c`、米杏 `#dbb8a1`：纸张折痕与辅助细节。

## 意象

信封作为开场与结尾，纸飞机承担横向及对角线运动，枫叶承担中心旋转与擦拭转场，邮票承担小卡片构图。中段信纸展开文字与地址线，后段拱顶和箱体组装为酒红信箱。所有对象均为独立 SVG 组件。

## 文字与构图

片名为 THE AUTUMN POST OFFICE。开场 a letter. 使用连写体，信件正文使用 Gaegu，标本卡「秋」使用 Zen Kurenaido。文字不依赖系统字体，加载完成才允许渲染。

保留居中卡片、横幅、散点卡片、物件组装与框线收尾的节奏。所有颜色、物件轮廓和画面内文案围绕秋日邮局统一；没有社交平台界面。

## 动画实现

总计 1113 帧，30 fps。所有变换依赖当前帧；纸纹使用固定噪声种子；配乐为本地新编写的 Letters in October，时长与画面一致。当前时序以 src/timing.ts 为准。

信箱组装使用同一组件内的拱顶与箱体：共享最终坐标与渐变，平滑插值缩放、位移、贴合；交接后继续使用相同组件，不依靠叠化更换物件。

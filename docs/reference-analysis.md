# 参考分析

原始录屏为 1920 × 1080，约 37.097 秒。画面内动画区域约位于 `(350, 216)`，宽约 1148、高约 646，接近 16:9。复刻将动画扩展为 1920 × 1080，固定 30 fps，总计 1113 帧。

## 构图

奶油白留白为主，使用居中竖卡、横向色带和椭圆作构图锚点。初始文字叠在风铃前；鱼群画面横向铺满；中段花朵用粉色方块对比；尾段以黄色播放器作为视觉焦点。录屏顶部和底部的播放器渐暗遮罩不属于画面设计，不予复刻。

## 颜色和材质

背景约 `#faf9ef`；薄荷绿 `#59d8b9`；水绿 `#14cbb8`；湖蓝 `#228cbd`；深蓝 `#28284b`；珊瑚粉 `#ed9098`；黄 `#f4d657`。参考存在屏幕录制及压缩，颜色为视觉取样近似。

色块具有纸面纤维、颜料沉积、透白斑驳与毛边。使用固定种子的多频率噪声滤镜实现，不依赖远程贴图。线条保持纤细，少用硬阴影，保留柔和水面倒影。

## 字体

标题 `collector?` 是深蓝细笔连写体；HELLO / ARE YOU / SUMMER SOUND COLLECTOR 为不规则手写大写。夏日徽章包含韩文、日文和汉字。用开源字体近似字形，加载完成后才允许渲染，避免机器缺字体造成回退差异。

## 节奏和转场

开场录屏约三秒停留于标题页，保留对应时间长度，以便音轨同步。之后约每两到四秒切换：竖向卡片移动、椭圆扩展、鱼群连续漂移、对角线上游、花瓣旋转与擦拭、音符平移、几何缩放组装、结尾框线描边。鱼塘部分停留稍长，末尾留白收束。

具体时序以 `src/timing.ts` 为准。视觉还原是重新绘制和程序动画，无法从录屏恢复原始路径、字体、纹理及完整关键帧曲线。
